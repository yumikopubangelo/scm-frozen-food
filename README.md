# SCM Galunggung Frozen Food

Aplikasi web Supply Chain Management untuk UMKM frozen food (fiktif) di Tasikmalaya:
supplier → gudang bahan baku → produksi → gudang barang jadi → reseller/toko.

Tugas UAS Sistem Informasi. Stack: Next.js 16 + TypeScript + Tailwind, Supabase (Postgres + Auth), Vercel.

- Konteks proyek & cara menjalankan: [`CLAUDE.md`](CLAUDE.md)
- Jurnal pembangunan per milestone: [`PROSES.md`](PROSES.md)

```bash
npm install
cp .env.example .env.local   # isi kredensial Supabase
npm run dev
```
